# TrafficSense 🚦
## Urban Traffic Flow Analytics & Congestion Prediction using Apache Spark

TrafficSense is a Big Data Analytics project that focuses on analyzing urban traffic data to identify congestion patterns and generate useful insights using Big Data technologies.

## Project Progress

### ✅ Phase 1: Project Setup
- Finalized project topic and objectives.
- Selected **Metro Interstate Traffic Volume Dataset**.

### ✅ Phase 2: Dataset Understanding
- Loaded dataset using Python Pandas.
- Performed initial data exploration:
  - Dataset size
  - Column analysis
  - Data types
  - Missing value checking
  - Duplicate record checking

### ✅ Phase 3: Data Preprocessing
- Removed duplicate records.
- Handled missing values.
- Converted `date_time` into datetime format.
- Extracted additional features:
  - Year
  - Month
  - Day
  - Hour
  - Day of Week
